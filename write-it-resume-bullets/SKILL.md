# Write IT Resume Bullets

Structure experience bullet points to showcase quantifiable outcomes and technical methodologies rather than passive lists of duties.

## The Google XYZ Formula
Every major achievement bullet must conform to this structure:
**"Accomplished [X] as measured by [Y], by doing [Z]"**

*   **X (Accomplishment/Impact):** What was achieved or the positive outcome. Start with a strong action verb (e.g., *Reduced*, *Optimized*, *Designed*).
*   **Y (Measurement/Metric):** Quantifiable success metric (e.g., latency, size reduction, scan coverage, memory savings, lines of code, volume of data, ticket count).
*   **Z (Method/Action):** The technical context, languages, frameworks, patterns, or tools used to achieve it.

## Metric Classification for IT
If direct business/revenue metrics are unavailable, utilize technical performance metrics:
- **Backend/Systems:** Latency reduction, throughput increase, memory/CPU consumption, queue size reduction, testing coverage, build success rates, volume of data processed.
- **Frontend/Mobile:** App startup time, bundle size reduction, performance scores, crash-free session rates, user retention/engagement increase.
- **Security/DevSecOps:** Audit finding reduction, time-to-remediate, vulnerability scanning coverage, number of false-positives eliminated, asset inventory expansion, severity rate reduction.

## Action Verbs
- *Creation/Development:* Designed, Implemented, Built, Developed, Architected, Engineered, Formulated.
- *Improvement/Optimization:* Optimized, Streamlined, Reduced, Accelerated, Restored, Enhanced, Mitigated.
- *Audit/Research:* Audited, Investigated, Analyzed, Validated, Evaluated, Reviewed, Traced.

## Rules & Constraints
- **Start with Action Verbs:** Never begin a bullet point with helper verbs, pronouns, or filler phrases (e.g., *Responsible for...*, *Helped to...*, *Assisted in...*, *I worked on...*).
- **Strong Technical Specificity:** Name the tools, languages, and frameworks (e.g., *Django*, *Vue.js*, *RabbitMQ*, *Frida*) in the **Z** component to ensure ATS visibility and technical credibility.
- **Strict Conciseness:** Keep bullets to 1-2 lines. Avoid long-winded setup or administrative filler.
- **Active Voice:** Write in the active past tense for completed experiences (or present tense for active tasks).
- **Never Use Buzzwords and Clichés:** Under no circumstances use corporate jargon, marketing fluff, or AI-generated filler. Strip them entirely and replace them with direct, factual descriptions.
  - *Forbidden Buzzwords:* spearheaded, leveraged, revolutionized, seamlessly, testament, key player, synergized, passionately, dynamically, meticulously, game-changer, cutting-edge, state-of-the-art, paradigm shift, go-getter, result-oriented, thinking outside the box, team player, fast-paced, proactive, optimization-focused.
